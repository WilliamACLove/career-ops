# Режим: interview-prep — Подготовка к собеседованию

Когда пользователь просит подготовиться к собеседованию в конкретной компании, или оценка ≥ 4.0 и статус обновлён на `Interview`.

## Входные данные

1. **Название компании** и **должность** (обязательно)
2. **Отчёт оценки** в `reports/` (если есть)
3. **Банк историй** `interview-prep/story-bank.md`
4. **CV** `cv.md` + `article-digest.md`
5. **Профиль** `config/profile.yml` + `modes/_profile.md`

## Шаг 1 — Исследование

WebSearch-запросы. Извлекать структурированные данные, не пересказы. Цитировать источники.

| Запрос | Что извлечь |
|--------|-------------|
| `"{company} {role} interview questions site:glassdoor.com"` | Реальные вопросы, сложность, таймлайн, кол-во раундов |
| `"{company} юрист отзывы собеседование"` | Общие отзывы о процессе найма (отраслевые форумы, СМИ) |
| `"{company} {role} тестовое задание юрист"` | Формат и тематика письменного задания (writing exercise), если применимо |
| `"{company}" Право.ру OR "Legal Insight"` | Позиционирование фирмы/юридического департамента на рынке, рейтинги, недавние сделки/дела |
| `"{company} собеседование отзывы site:habr.com"` | Отзывы на русском о процессе собеседования (особенно полезно для инхаус-ролей в tech-компаниях) |
| `"{company} отзывы собеседование site:hh.ru"` | Отзывы кандидатов на hh.ru |

**НЕ выдумывать вопросы.** Выведенные из JD — помечать `[выведено из JD]`.

## Шаг 2 — Обзор процесса

```markdown
## Обзор процесса
- **Раунды:** {N} раундов, ~{X} дней от начала до конца
- **Формат:** {напр., скрининг HR → интервью с партнёром → письменное задание → callback → финал с руководителем департамента}
- **Сложность:** {X}/5 (среднее Glassdoor, N отзывов)
- **Позитивный опыт:** {X}%
- **Особенности:** {напр., "письменное задание вместо устного кейса", "без формального тестового, только обсуждение matters из деал-шита"}
- **Источники:** {ссылки}
```

## Шаг 3 — Разбор по раундам

```markdown
### Раунд {N}: {Тип}
- **Длительность:** {X} мин
- **Проводит:** {коллега / менеджер / skip-level / рекрутер}
- **Что оценивают:** {конкретные навыки}
- **Зафиксированные вопросы:**
  - {вопрос} — [источник: Glassdoor 2026-Q1]
- **Как готовиться:** {1-2 конкретных действия}
```

## Шаг 4 — Вероятные вопросы

### Профессиональные (практика права)
Вопросы по конкретным типам сделок/дел, отраслевому регулированию, знанию практики, аналитическим/письменным заданиям (memo, анализ проекта договора).

### Поведенческие
Вопросы про лидерство, конфликты, коллаборацию, неудачи.
Для каждого — какая история из `story-bank.md` подходит лучше всего.

### Специфичные для роли
Вопросы, привязанные к конкретному JD (с учётом архетипа).

### Red flags в бэкграунде
Вопросы, которые интервьюер вероятно задаст про пробелы, переходы или необычные элементы в бэкграунде. Читать `_profile.md` и `cv.md`.

## Шаг 5 — Маппинг банка историй

| # | Вероятный вопрос/тема | Лучшая история из story-bank.md | Fit | Пробел? |
|---|----------------------|-------------------------------|-----|---------|

- **strong**: история прямо отвечает на вопрос
- **partial**: история смежная, нужен рефрейминг
- **none**: нет подходящей → отметить для пользователя

## Шаг 6 — Чеклист технической подготовки

```markdown
- [ ] {тема} — почему: "{доказательство из исследования}"
- [ ] {тема} — почему: "{их блог/продукт говорит, что это важно}"
```

Приоритизировать по частоте и релевантности. Максимум 10 пунктов.

## Шаг 7 — Сигналы компании

- **Ценности, на которые скринят:** назвать, цитировать источник
- **Словарь для использования:** внутренние термины компании
- **Чего избегать:** анти-паттерны из отзывов
- **Вопросы им:** 2-3 острых вопроса, демонстрирующих домашнюю работу

## Специфика российских юридических собеседований 🇷🇺

### Типичные раунды в российских юрфирмах и инхаус-командах
Раунды соответствуют канонической английской типологии (screen | hiring-partner | callback | writing-exercise | panel | business-stakeholder | behavioral), локализованной под то, как реально проходит найм на российском юридическом рынке:

1. **Скрининг HR (screen)** (20-30 мин): мотивация, зарплатные ожидания (gross/net), готовность к переезду/формату работы
2. **Интервью с партнёром/руководителем практики (hiring-partner)** (45-60 мин): опыт по конкретным сделкам/делам, глубина экспертизы в практике, ведение клиентов
3. **Письменное задание (writing-exercise)**: обычно асинхронно (take-home) — анализ проекта договора, составление меморандума по вопросу, иногда под таймер на площадке
4. **Повторное интервью (callback)** (в крупных фирмах): встреча с несколькими партнёрами/старшими юристами в течение одного дня
5. **Панельное интервью (panel)** (чаще в инхаус): встреча с несколькими стейкхолдерами одновременно — руководитель юридического департамента + профильные юристы
6. **Интервью с бизнес-стейкхолдером (business-stakeholder)** (для инхаус-ролей): встреча с представителем бизнес-подразделения, оценка навыка объяснять юридические риски простым языком
7. **Финальное собеседование (behavioral / поведенческое)**: с управляющим партнёром или руководителем юридического департамента — ценности, культурный fit, причины смены места

Крупные банки и финтех с большими юридическими/комплаенс-департаментами (напр. системно значимые банки) нередко используют более структурированный, многоэтапный процесс, ближе к корпоративному найму, чем к традиционному найму в юрфирме.

### Частые вопросы на российских юридических собеседованиях
- "Расскажите о себе" (2-3 минуты, структурированно)
- "Почему уходите с текущего места/фирмы?"
- "Зарплатные ожидания?" (уточнить gross/net)
- "Готовность к переезду / формату работы?"
- "Расскажите о самой сложной сделке/деле"
- "Как выстраиваете отношения с клиентом/бизнес-подразделением?"
- "Почему не стали/не хотите становиться адвокатом?" (если применимо к практике)
- Письменное задание: "Проанализируйте проект договора и укажите ключевые риски" / "Составьте меморандум по вопросу X"

### Формат STAR+R на русском
- **С (Ситуация):** Контекст и вводные
- **З (Задача):** Что нужно было сделать
- **Д (Действия):** Что конкретно сделал
- **Р (Результат):** Измеримый результат
- **О (Осмысление):** Что понял, что сделал бы иначе

## Вывод

Сохранить отчёт в `interview-prep/{company-slug}-{role-slug}.md`.

```markdown
# Подготовка к собеседованию: {Компания} — {Роль}

**Отчёт:** {ссылка на отчёт оценки или "N/A"}
**Исследовано:** {YYYY-MM-DD}
**Источники:** {N} отзывов Glassdoor, {N} материалов Право.ру/Legal Insight, {N} прочих
```

## Правила

- **НИКОГДА не выдумывать вопросы и приписывать их источникам.**
- **НИКОГДА не фабриковать рейтинги Glassdoor.**
- **Цитировать всё.** Каждый вопрос, каждая статистика получает источник или тег `[выведено]`.
- Генерировать на языке JD (RU по умолчанию для русскоязычных вакансий).
- Быть прямым. Это рабочий документ подготовки, не мотивационная речь.
