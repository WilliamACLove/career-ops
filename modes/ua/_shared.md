## Система оцінювання

Оцінка використовує 6 блоків (A-F) з глобальним балом 1-5:

| Вимір                    | Що оцінює                                                    |
| ------------------------ | ------------------------------------------------------------ |
| Збіг з CV                | Навички, досвід, proof points alignment                      |
| Відповідність North Star | Наскільки роль збігається з цільовими архетипами кандидата   |
| Компенсація              | Зарплата vs ринок (5 = верхній квартиль, 1 = значно нижче)   |
| Культурні сигнали        | Культура компанії, зростання, стабільність, віддалена робота |
| Red flags                | Блокери, попередження (негативні коригування)                |
| **Глобальний**           | Зважене середнє                                              |

**Інтерпретація балів:**

- 4.5+ → Сильний збіг, рекомендується відгукнутися одразу
- 4.0-4.4 → Гарний збіг, варто відгукнутися
- 3.5-3.9 → Нормально, але не ідеально; відгукуватися лише за наявності конкретної причини
- Нижче 3.5 → Наполегливо рекомендується не відгукуватися (див. Ethical Use в CLAUDE.md)

### Юридичні hard gates (pass/fail — ніколи не усереднюються мовчки)

Перевіряти ЦЕ ПЕРЕД зважуванням вимірів. Гейти читають блок `legal:` у `config/profile.yml` (`class_year`/роки досвіду, `bar_admissions`/кваліфікація, `patent_bar`, `practice_areas`, `recruiter_channel`). Провалений гейт має ЯВНО з'явитися у вимірі Red flags І як окремий рядок у звіті — сильний збіг з CV ніколи не компенсує і не приховує провалений гейт.

1. **Кваліфікація / статус адвоката** — звірити вимоги вакансії з кваліфікацією кандидата. Суворість залежить від типу роботодавця:
   - **Юридичні фірми (особливо судова практика): суворо.** Представництво в суді за загальним правилом вимагає статусу адвоката (свідоцтво про право на заняття адвокатською діяльністю, отримане через кваліфікаційний іспит, стажування та складання присяги, членство в Національній асоціації адвокатів України). Транзакційні/консультаційні ролі у фірмах іноді відкриті для юристів без адвокатського статусу — перевіряти формулювання конкретної вакансії, а не припускати.
   - **Inhouse (юрисконсульт): помірно.** Штатний юрист компанії у багатьох випадках може консультувати та представляти роботодавця без окремого адвокатського свідоцтва — вимога залежить від типу справи та інстанції. Трактувати як помірний фактор, а не блокер, якщо вакансія прямо не вимагає адвокатського статусу.
   - **Державний сектор і legal tech: мінімально.** Державна служба (прокуратура, суддівство, держоргани) має власну окрему кваліфікаційну процедуру (конкурс, кваліфікаційні іспити для суддів/прокурорів) — це інша кваліфікація, не адвокатура. Для legal tech зазвичай достатньо вищої юридичної освіти.
   - **Правила щодо обсягу адвокатської монополії на представництво в суді (зокрема винятки для юрисконсультів і трудових спорів) неодноразово змінювалися і мають перехідні положення.** Якщо не впевнені у поточному стані вимоги для конкретного типу справи чи інстанції — зазначте це прямо в звіті й порадьте кандидату перевірити самостійно, а не вгадуйте формулювання закону.
2. **Рівень досвіду / PQE-банд** — український ринок здебільшого не використовує жорстку систему "class of 20XX", як у BigLaw; типовіше — банди за роками практики (junior/middle/senior/counsel/партнер) або пряма вказівка кількості років. Фірми, орієнтовані на міжнародних клієнтів, у вакансіях для латеральних переходів дедалі частіше вживають термін **PQE** (post-qualification experience). Порівняти заявлений в CV/профілі досвід із зазначеним у вакансії бандом; вихід за межі банду в латеральній вакансії фірми — сильний негативний сигнал (майже автоматична відмова на скринінгу) — рекомендувати не подаватися без конкретної причини.
3. **Патентний повірений** — ролі, пов'язані з патентним діловодством (patent prosecution), вимагають реєстрації як патентний повірений — ОКРЕМА кваліфікація від адвокатського статусу, що підтверджується окремим кваліфікаційним іспитом і внесенням до Державного реєстру патентних повірених України. Якщо вакансія цього прямо вимагає, а `legal.patent_bar` — false, це hard gate. (Товарні знаки, авторське право та IP-судові спори зазвичай цього не вимагають.)
4. **Ризик конфлікту інтересів (senior/партнерський рівень)** — будь-який латеральний перехід на senior/партнерський рівень залежить від проходження перевірки на конфлікт інтересів із клієнтами нового роботодавця; один конфлікт з клієнтом може повністю зупинити кандидатуру. Зазначити ризик у звіті — не оцінювати балом.

## Легітимність вакансії (Блок G)

Блок G оцінює, чи є вакансія реальною і активною. НЕ впливає на глобальний бал 1-5 — це окрема якісна оцінка.

**Три рівні:**

- **Висока впевненість** — Реальна, активна вакансія (більшість сигналів позитивні)
- **Обережно** — Змішані сигнали, варто зазначити (деякі занепокоєння)
- **Підозріло** — Множинні індикатори ghost-вакансії, користувач має перевірити спочатку

**Ключові сигнали (зважені за надійністю):**

| Сигнал                      | Джерело          | Надійність | Примітки                                                                         |
| ---------------------------- | ----------------- | ----------- | ---------------------------------------------------------------------------------- |
| Вік публікації              | Знімок сторінки  | Висока     | До 30 днів = добре, 30-60 = змішано, 60+ = тривожно (з поправкою на тип ролі)    |
| Кнопка Apply активна        | Знімок сторінки  | Висока     | Прямий спостережуваний факт                                                      |
| Конкретика практики в JD    | Текст JD         | Середня    | Загальні JD корелюють з ghost-вакансіями, але можуть бути просто погано написані. "Конфіденційна юридична фірма" через рекрутера без назви роботодавця й банду досвіду — теж слабший сигнал |
| Реалістичність вимог        | Текст JD         | Середня    | Суперечності (наприклад, "молодший юрист" + відповідальність рівня partner) — сильний сигнал, розмитість — слабший |
| Новини про скорочення       | WebSearch        | Середня    | Враховувати відділ, час і розмір компанії                                        |
| Повторна публікація         | scan-history.tsv | Середня    | Та сама роль 2+ рази за 90 днів — тривожно; та сама вакансія, розміщена кількома агентствами водночас, — фірма "прогонює" контингентний ринок |
| Прозорість зарплати         | Текст JD         | Низька     | В Україні відсутність вказаної зарплати — норма ринку, а не сигнал нечесності    |
| Відповідність роль-компанія | Якісна оцінка    | Низька     | Суб'єктивно, використовувати лише як допоміжний сигнал                           |

**Специфічні для юридичного ринку сигнали:**

- **"Конфіденційна компанія" через рекрутингове агентство:** контингентні рекрутери часто публікують вакансії без назви роботодавця, щоб зібрати резюме без реального відкритого мандату. Не автоматично фейк, але без назви роботодавця, банду досвіду й конкретики практики — зважати як "Обережно".
- **Аутстафінг/аутсорсинг юридичних послуг, поданий як штатна вакансія "юрист":** ключові слова "проєктна робота", "погодинна оплата", "аутстафінг", агентство як формальний роботодавець. Це реальні пропозиції, але не кар'єрні латеральні переходи — позначити, щоб кандидат не оцінював їх як таку саму позицію.
- **Платні "послуги працевлаштування":** легітимні юридичні рекрутери ЗАВЖДИ отримують оплату від роботодавця (комісія), ніколи не беруть плату з кандидата. Будь-яка пропозиція заплатити за "розміщення", "реєстрацію" чи "просування" резюме — ознака шахрайства, позначати як "Підозріло".

**Етичний підхід (ОБОВ'ЯЗКОВИЙ):**

- Це допомагає користувачам пріоритизувати час на реальні можливості
- НІКОЛИ не представляти висновки як звинувачення в нечесності
- Представити сигнали і дозволити користувачу вирішити
- Завжди зазначати легітимні пояснення для тривожних сигналів

## Специфіка українського ринку 🇺🇦

### Компенсація

- **Валюта**: У юридичних фірмах та inhouse-ролях в українських і міжнародних компаніях зарплати часто обговорюються в **USD**, особливо для senior/partner-рівня та ролей з міжнародними клієнтами; для держсектору, громадських організацій та більшості штатних позицій у місцевих компаніях — у гривні (₴ / UAH).
- **Gross vs Net**: Для ФОП (трапляється серед незалежних консультантів і в legal tech) — зазвичай обговорюється net-сума, податки — відповідальність ФОП. Для штатних (типова форма для юристів фірм та inhouse) — уточнити `gross` чи `на руки (net)`. ПДФО: 18% + військовий збір 5% (станом на 2024+; уточнювати актуальну ставку — військовий збір підвищувався).
- **Джерела даних**: галузеві юридичні видання та рейтинги (напр., «Юридична практика» / Ukrainian Legal Gazette публікують огляди ринку та рейтинги фірм — трактувати як орієнтир, а не точні цифри), розділи зарплат на robota.ua та work.ua, LinkedIn для міжнародних/inhouse позицій. DOU.ua/salaries та djinni.co/salaries релевантні лише для legal tech та inhouse-ролей у tech-компаніях (юрист/юрисконсульт при IT-продукті) — не для класичної фірмової чи держсекторної практики.
- **Бонуси**: Великі та середні юридичні фірми нерідко мають річний дискреційний бонус, прив'язаний до білінгу/показників; це не такий структурований лockstep, як у BigLaw США — трактувати опубліковані діапазони обережно. Inhouse-бонуси частіше квартальні/річні, прив'язані до KPI компанії.

| **ФОП + Дія City**     | ФОП через резидента Дія City. Гіг-контракт зі спеціальним захистом                     | Inhouse-юрист/комплаєнс-спеціаліст у tech-компанії — резиденті Дія City | +0.1 до стабільності (додатковий захист) |
| **ГПД**                | Цивільно-правовий договір. Мінімальний захист                                          | Разові юридичні проєкти, консультування                                | -0.2 до стабільності                     |
| **B2B (міжнародний)**  | Контракт з іноземною компанією через ФОП                                               | Inhouse/legal counsel для іноземних компаній, remote-контракти         | Нейтрально (стандарт для remote)         |

> **Дія City** — спеціальний правовий режим для ІТ-компаній в Україні; актуальний для юридичних ролей лише коли роботодавцем є резидент Дія City (наприклад, inhouse-юрист у продуктовій IT-компанії).

### Податки (для ФОП 3-тя група)

- **Єдиний податок**: 5% від доходу
- **ЄСВ** (єдиний соціальний внесок): мінімальний розмір
- **Для штатних**: ПДФО 18% + військовий збір + ЄСВ (сплачує роботодавець) — уточнювати актуальну ставку військового збору
- **Дія City (гіг-спеціалісти)**: пільгова ставка ПДФО + військовий збір за спеціальним режимом

### Трудове право (КЗпП)

- **Випробувальний термін**: до 3 місяців (до 6 для керівних посад, зокрема керівника юридичного департаменту)
- **Відпустка**: мінімум 24 календарні дні за КЗпП
- **Лікарняний**: оплачується з фонду соціального страхування + можлива доплата роботодавця
- **Звільнення**: відпрацювання 2 тижні (за угодою сторін — без відпрацювання)
- **Для ФОП**: жодних гарантій за КЗпП — усе визначається договором

### Ринок праці та професійні органи (особливості)

- **Кваліфікація адвоката**: свідоцтво про право на заняття адвокатською діяльністю видається після кваліфікаційного іспиту, стажування та складання присяги; членство і статус можна перевірити через Єдиний реєстр адвокатів України (ЄРАУ), що адмініструє Національна асоціація адвокатів України (НААУ). Юрист без адвокатського статусу (просто "юрист"/"юрисконсульт") — окрема, ширша категорія, не обмежена представництвом у суді.
- **Патентні повірені** — окрема професія та окремий державний реєстр (не адвокатура); релевантно для IP-ролей, пов'язаних із патентним діловодством.
- **robota.ua**, **work.ua** — головні загальні портали для юридичних вакансій в Україні (фірми, inhouse, держсектор, комплаєнс).
- **DOU.ua**, **Djinni.co** — релевантні для legal tech та inhouse-юридичних/комплаєнс-ролей у tech-компаніях, а не для класичної фірмової практики.
- **LinkedIn** — основний канал для міжнародних inhouse-позицій та вакансій у фірмах з іноземними клієнтами.
- **Провідні українські юридичні фірми** (орієнтир, не вичерпний список) — напр., Asters, Sayenko Kharenko, Avellum та подібні за категорією "провідна фірма повного циклу"; галузеве видання «Юридична практика» (Ukrainian Legal Gazette) щороку публікує рейтинги фірм.
- **Рекрутинговий канал**: для латеральних переходів у фірми та senior inhouse-ролей юридичні рекрутери/хедхантери відіграють таку саму роль, як і в інших країнах — перший рекрутер, що подав кандидата роботодавцю, зазвичай "закріплює" кандидатуру за собою на певний період. Ніколи не подавати пряму заявку до роботодавця, якщо рекрутер уже подав (або веде перемовини щодо подання) кандидата туди — див. правило нижче в «Глобальні правила».
- **Релокація/timezone**: багато українських юристів (особливо inhouse і legal tech) працюють з-за кордону — уточнювати вимоги щодо timezone overlap та можливості дистанційної роботи з-за кордону.

## Глобальні правила

### НІКОЛИ

1. Вигадувати досвід або метрики
2. Модифікувати cv.md або файли портфоліо
3. Надсилати відгуки від імені кандидата
4. Ділитися телефоном у генерованих повідомленнях
5. Рекомендувати компенсацію нижче ринку
6. Генерувати PDF без попереднього читання JD
7. Використовувати канцелярит і корпоративну мову
8. Ігнорувати трекер (кожна оцінена вакансія реєструється)
9. Готувати або подавати пряму заявку до юридичної фірми, якщо юридичний рекрутер уже подав (або веде перемовини щодо подання) кандидата туди — перший рекрутер зазвичай "закріплює" кандидатуру за собою на ~6-12 місяців (referral-source lock), а подвійна подача зазвичай призводить до відхилення кандидата обома каналами. ЗАВЖДИ перевіряти `legal.recruiter_channel` у `config/profile.yml` та поле `via=` у трекері перед підготовкою заявки до фірми

### ЗАВЖДИ

0. **Супровідний лист:** Якщо форма дозволяє, ЗАВЖДИ включати. Той самий дизайн, що й CV. Цитати з JD, прив'язані до proof points. Максимум 1 сторінка.
1. Читати cv.md, \_profile.md та article-digest.md (якщо є) перед оцінкою
   1b. **Перша оцінка в сесії:** Запустити `node cv-sync-check.mjs`. Якщо є попередження — повідомити користувача.
2. Визначити архетип ролі та адаптувати фреймінг за \_profile.md
3. Цитувати точні рядки з CV при збігу
4. Використовувати WebSearch для дослідження компенсації та даних про компанію
5. Реєструвати в трекері після оцінки
6. Генерувати контент мовою JD (UA за замовчуванням для україномовних вакансій, EN для англомовних)
7. Бути прямим і конкретним — без води
8. Для україномовних вакансій: технічна українська, короткі речення.
   8b. URL-и кейсів у Professional Summary PDF (рекрутер може прочитати тільки це). Статус адвоката/номер посвідчення (якщо релевантно) — на видному місці у верхній частині CV.
9. **Додавання до трекера як TSV** — не додавати НОВІ записи в `data/applications.md` напряму; для нових записів писати TSV у `batch/tracker-additions/` і робити merge. Пряме редагування існуючих рядків допустиме для оновлення `status`/`notes`.
10. **Включати `**URL:**` в заголовок кожного звіту.**

## Professional Writing та ATS-сумісність

Ці правила застосовуються до ВСЬОГО генерованого тексту для кандидата: PDF-резюме, буллети, супровідні листи, відповіді у формах, повідомлення в LinkedIn. НЕ застосовуються до внутрішніх звітів оцінки.

### Уникати кліше

- "Я захоплений..." / "Passionate about..." / "результат-орієнтований" / "results-driven"
- "великий досвід" / "extensive experience" / "proven track record"
- "Задіяв" / "Leveraged" (називати конкретний інструмент)
- "Очолив" / "Spearheaded" (використовувати "керував" / "led" або "запустив" / "launched")
- "Забезпечив взаємодію" / "Facilitated collaboration" (використовувати "організував" / "set up")
- "Синергія" / "Synergy" / "комплексний" / "comprehensive" / "інноваційний" / "innovative"
- "У сучасному швидкоплинному світі" / "In today's fast-paced environment"
- "продемонстрована здатність" / "demonstrated ability to" / "best practices" (назвати конкретну практику)

### Юнікод-нормалізація для ATS

`generate-pdf.mjs` автоматично нормалізує em-dash, розумні лапки та zero-width символи в ASCII для максимальної ATS-сумісності. Але краще не генерувати їх взагалі.

### Різноманітність структури речень

- Не починати кожен буллет одним і тим самим дієсловом
- Чергувати довжину речень (коротко. Потім довше з контекстом. Знову коротко.)
- Не завжди використовувати "X, Y та Z" — іноді два пункти, іноді чотири

### Конкретика замість абстракцій

- "Провів due diligence і закрив угоду M&A обсягом $40М за 6 тижнів" краще, ніж "супроводжував угоди"
- "Другий співдоповідач у 3-тижневому арбітражі МКАС; підготував заперечення, яке зняло 60% заявлених вимог" краще, ніж "великий досвід судової практики"
- Називати типи угод, суми угод, кількість справ і командну роль, коли дозволено конфіденційністю. Клієнтів називати лише якщо справа публічна (угода оголошена / справа відкрита в реєстрі) — інакше описувати узагальнено ("клієнт — фінансова установа з топ-10 банків України")
