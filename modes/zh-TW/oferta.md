# 模式: job — 完整的 A-G 維度評估

當求職者輸入職缺描述（JD 文字或 URL 連結）時，**一律**輸出以下七個維度的深度評估結果（A–F 評估 ＋ G 真實性）：

## 步驟 0 — 職缺原型辨識

將該職缺歸類為 6 種原型之一（參見 `_shared.md`）。若為混合型，標明最接近的 2 種。這會決定：
- 在維度 B 中優先比對哪些量化佐證（Proof points）。
- 在維度 E 中如何改寫履歷的專業摘要。
- 在維度 F 中優先準備哪些 STAR 故事。

---

## 步驟 0.5 — 法律職缺硬性門檻檢查（通過／不通過，絕不平均掩蓋）

在給任何維度評分之前，先依 `_shared.md` 的「法律職缺的硬性門檻」對照 `config/profile.yml` 的 `legal` 區塊逐項檢查。這是結構性篩選，不是加權因子——未通過的門檻必須**明確**寫在紅旗警告維度，也要出現在最終建議裡，不能被漂亮的履歷匹配度悄悄蓋過去。

1. **律師執照與公會資格** — 依雇主類型套用寬嚴不同的標準：**事務所嚴格**（須持有律師證照並加入律師公會，沒有模糊空間）；**企業法務寬鬆**（多數「法務」職缺不強制要求律師執照，屬加分項，除非 JD 明確要求）；**法遵與法律科技最寬鬆**（通常不要求律師資格）。若求職者同時考慮香港職缺，另外註明 solicitor／barrister 雙軌制與 PCLL 資格的差異。
2. **年資／職級對應** — 台灣事務所以執業年資與職稱（受雇律師 → 資深律師 → 合夥律師）為主要級距依據，不像美國 BigLaw 有嚴格的 class-year 制度。JD 載明的年資區間（如「3–5 年執業經驗」）若與求職者的年資有落差，在報告中明確指出落差幅度，但不視為自動淘汰——台灣事務所的職級認定彈性通常較大。
3. **專利師資格** — 若 JD 要求辦理專利申請代理業務，而求職者未具備專利師登錄資格，視為硬性門檻（純專利訴訟代理不受此限）。
4. **利益衝突風險（資深／合夥人職缺）** — 註記需經客戶利益衝突查核的風險，不納入評分。
5. **僱傭 vs 委任關係** — 若能從 JD 或公開資訊判斷該事務所以「委任」而非「僱傭」關係聘任受雇律師，於報告中提示求職者向事務所確認契約性質對勞動保障（資遣費、特休）的影響。

在維度 B 的最上方，用簡短的通過／不通過表格呈現以上檢查結果。任何一項未通過，都會限制最終建議的積極程度，無論其他維度分數多高。

## 維度 A — 職缺概覽 (Role Summary)

輸出包含以下資訊的表格：
- 偵測到的角色原型 (Archetype detected)
- 執業領域 (Domain － 交易／訴訟／企業法務／法遵／政府／法律科技)
- 職務機能 (Function － 顧問／談判／訴訟／管理／建置)
- 資深程度 (Seniority － 執業年資／職稱級距，或企業法務的職級)
- 工作模式 (Remote － 全遠端／混合／進辦公室)
- 團隊規模 (Team size － 若 JD 中有提及)
- 一句話總結 (TL;DR)

---

## 維度 B — 履歷匹配分析 (Match with CV)

讀取 `cv.md`。建立一個對照表格，把 JD 中的各項硬性／軟性條件一一對應到履歷中的具體行號與量化敘述上。

**針對不同職缺原型的分析側重點：**
- **事務所受雇律師 — 商務／交易組** → 側重相符資深度的交易經驗：交易類型、標的規模、草擬文件的主導程度、專案工作分工的管理能力。
- **事務所受雇律師 — 訴訟組** → 側重出庭與攻防經驗：參與過的開庭、書狀撰擬與具名程度、仲裁／訴訟角色、寫作能力。
- **企業法務 — 產品／商務／個資** → 側重合約處理量（SaaS/MSA/DPA 件數）、跨部門諮詢能力、法規涵蓋廣度、對非法律背景同事的白話溝通能力。
- **法遵與法規遵循** → 側重具名的法規領域經驗（洗錢防制、金融監理、個資法）、與主管機關互動經驗、調查案件經驗、制度建置成果。
- **公部門／公益律師** → 側重出庭量、審級經驗、公益投入的具體佐證（法扶案件、公益服務、學生社團經驗）。
- **法律科技／法律工程師** → 側重優質事務所／法務資歷 **加上** 對產品／科技工具的真實掌握度——曾建置的範本、自動化過的流程、法律科技相關的副業或專案。

**能力落差 (Gaps) 與彌補策略：**
針對辨識出的每一項能力落差，提供以下因應方案：
1. 這是硬性門檻（Blocker）還是加分項（Nice-to-have）？
2. 求職者是否有其他相近或可遷移的經驗可以等價替換？
3. 是否可以透過一個快速的作品或文章來補上這個空白？
4. 具體的彌補行動指南（如在求職信中如何避重就輕、準備怎樣的話術）。

---

## 維度 C — 職級判斷與求職策略 (Level and Strategy)

1. **JD 所對應的實際職級** vs **求職者針對該原型的自然職級**——事務所職缺以執業年資／職稱對應（受雇律師 → 資深律師 → 合夥律師），企業法務則以職級階梯對應（法務專員 → 法務主管 → 法務長），**職稱本身就是薪酬的槓桿**。
2. **「凸顯資深度（實事求是）」計畫**：提供針對該原型的特定自我推薦話術，具體點出可展示資深度的案件／交易，以及如何把事務所訓練、書記官／法官助理經歷或主管機關經驗轉化為競爭優勢。
3. **「如果對方給的職級偏低」預案**：事務所職缺——年資認定通常可在核發 offer 階段小幅調整（±1 年，有時降年資換取合夥升遷的緩衝期）；企業法務——先爭取職級（法務主管 vs 法務專員）再談金額，因為獎金比例與股權／分紅級距通常跟著職稱走。

## 維度 D — 薪酬競爭力與市場需求 (Comp and Demand)

使用 WebSearch 工具查詢：
- 該職缺的當前市場薪資範圍——**法律職缺優先查 104 人力銀行薪資情報、1111 人力銀行薪資探索**；一般求職網站（Glassdoor、Levels.fyi、Blind 等）多以科技業樣本為主，法律職缺參考價值有限，僅在缺乏其他資料時輔助佐證。台灣沒有公開的事務所薪級表，查無資料時如實告知求職者，不要臆測數字。
- 該雇主在業界的薪酬信譽（如勞健保是否以實際薪資投保、年終獎金是否確實發放、加班費／加班補休是否落實）。
- 該職缺的市場需求趨勢（是急徵職缺，還是長期掛在人力銀行的儲備缺）。

在解讀薪資數字之前，必須先判斷公司類型。公開的薪資區間不能直接等同於契約上的固定本薪或穩定入袋的金額。

**公司類型分類（必填，法律職缺）：**

將招募主體歸入最接近的一類，並給出信心水準：

| 公司類型 | 典型薪資可信度 | 辨識訊號 |
|---|---|---|
| 大型綜合律師事務所（指標性大所或同量級事務所） | 中 | 案源穩定、分工細緻，但本薪多為面議；「大所」是類別而非固定名單 |
| 中小型 / 精品事務所（特定領域專精） | 中到低 | 團隊小、案源集中，薪資彈性大 |
| 企業法務（一般企業） | 中 | 職級體系存在，公開薪資資訊少 |
| 企業法務（金融業／上市櫃公司） | 中到高 | 受主管機關監理，職級與薪酬結構較透明 |
| 法遵 / 風控（金融業） | 中 | 徵才常態化，證照與經歷要求明確 |
| 政府機關 / 國營事業 | 高 | 依俸給表／機構薪資規定敘薪，透明但市場競爭力偏低 |
| 公益法律扶助 / NGO | 中到高 | 薪資公開度較高，但明顯低於市場行情 |
| 法律科技新創 / 產品公司 | 中到低 | 團隊小，薪資可能混合本薪與選擇權 |
| 獵頭 / 法律人力仲介職缺 | 低到中 | 第三方刊登（常見「機密事務所」「知名外商法務」等匿名徵才），薪資可能反映客戶預算而非最終 offer |

如果品牌方與實際招募／簽約主體不同，優先按**實際契約主體／用人主體**分類，再說明品牌關係。公司類型不確定時，標記為 `Unknown`，薪資可信度預設採用保守等級：`低`。

**薪資可信度（必填）：**

先檢查 JD 本身是否有薪資／報酬資訊。若 JD 沒有任何公開的薪資數字，也沒有「薪資面議」「待遇從優」「依公司規定」「本薪＋績效獎金」「含全勤」「最高可達」等模糊報酬表述，本節在需求趨勢之後只輸出兩行：

- **公司類型：** {類別或 `Unknown`} — {信心水準 ＋ 一個證據短語}
- **薪資可信度：** {等級} — JD 未提供薪資／報酬資訊；跳過薪資組成拆解、詳細市場數據表與 HR 查證問題

> **台灣特別注意：** 依《就業服務法》第 5 條，經常性薪資未達新臺幣 4 萬元的職缺**必須公開薪資範圍**。若一個明顯低於 4 萬的職缺卻寫「面議」，這本身就是一個負面訊號，應在此註記。

當 JD 明確寫出薪資數字，或僅出現「薪資面議」「待遇從優」「依公司規定」「本薪＋績效獎金」「含全勤」「最高可達」「上不封頂」等模糊報酬表述時，進入完整的薪資可信度路徑，並拆解以下五項：

- **公開薪資區間：** JD 原文寫出的薪資，必須逐字保留。
- **可能的契約固定本薪：** 對勞動契約中固定薪資的保守估計。
- **浮動／條件性現金組成：** 績效獎金、全勤獎金、業績獎金、津貼、加班費、年終獎金、專案獎金等現金項目。
- **預估穩定現金收入：** 大機率穩定發放的現金部分。除非在地資料足夠，否則預設以稅前口徑說明；不要把福利算進穩定現金。
- **非現金福利：** 選擇權、勞健保、勞退提繳、伙食津貼、交通補助、教育訓練預算、設備等不等同於固定現金的福利。

可信度分級：

| 等級 | 意義 |
|---|---|
| 高 | 明確寫為固定本薪，或有公開薪級／多方一致的資料佐證 |
| 中 | 區間大致可信，但薪資組成未完全拆開 |
| 低 | 公開數字很可能包含績效、全勤、業績獎金、津貼或「最高可達」的部分 |
| Unknown | 沒有可用的薪資資料 |

遇到以下表述，除非固定本薪單獨寫清楚，否則預設按低可信處理：「薪資面議」「待遇從優」「依公司規定」「最高可達」「上不封頂」「本薪＋業績獎金」「含津貼」「含績效」「含全勤」「KPI 獎金」「保障年薪 14 個月（未載明本薪）」，或跨度異常大的薪資區間。

當 JD 明確寫出薪資數字，或出現模糊報酬表述時，必須給出 3–6 個 HR 查證問題，例如：

- 勞動契約上寫明的固定本薪是多少？
- 公開薪資是否包含績效獎金、全勤獎金、業績獎金、津貼、加班費或年終獎金？
- 「保障年薪 N 個月」是否白紙黑字寫進契約，還是只是慣例？
- 試用期薪資是否打折？勞健保與勞退是否以**實際薪資**投保（而非高薪低報）？
- 哪些組成是每月固定發放，哪些取決於出勤、KPI 或公司盈餘？
- 若包含選擇權或員工酬勞（分紅），既得期間、歷史發放紀錄與實際預期價值是多少？
- 是否為「責任制」？若是，該職務是否經勞動部核定公告適用勞基法第 84-1 條，並經地方主管機關核備？（多數企業法務／法遵職務不在核定清單內，須逐一查證，不能憑職稱推定）
- 若為事務所受雇律師：與事務所之間是「僱傭」還是「委任」關係？這會直接影響資遣費、特休等勞動保障是否適用。

當 JD 明確寫出薪資數字，或出現模糊報酬表述時，以表格形式呈現查到的資料並標明來源。如果除了 JD 原文之外找不到可靠資料，如實說明，切勿捏造。
除非來源明確支持，否則不要把徵才廣告上的薪資當成實際入袋。

## 維度 F — 面試準備計畫 (Interview Plan)

依 JD 的具體要求，從求職者的工作經驗中篩選並重新包裝 6–10 個 STAR+R 故事（STAR ＋ **Reflection／反思**）：

| # | 對應 JD 需求 | 故事名稱 | 情境 (S) | 任務 (T) | 行動 (A) | 結果 (R) | 反思與總結 (Reflection) |
|---|---|---|---|---|---|---|---|

在**反思**欄中，務必提煉出學到的核心教訓，或如果重來一次會怎麼改進。這對展現資深度至關重要——資淺的候選人只描述過程，資深的候選人能提煉方法論。

**故事庫同步：** 若存在 `interview-prep/story-bank.md`，檢查這些故事是否已在故事庫中。若不存在，將其附加進去，以便隨著評估逐步建立一個隨時可調用的「黃金面試故事庫」。

**依原型包裝故事：**
- **事務所受雇律師 — 商務／交易組** → 強調交易執行力、文件草擬的主導程度、跨專業分工的協調管理。
- **事務所受雇律師 — 訴訟組** → 強調案件策略、勝訴或有利結果的攻防、開庭與書狀撰擬的臨場表現。
- **企業法務 — 產品／商務／個資** → 強調「安全地成事」（getting to yes safely）的商業判斷、合約量能、跨部門諮詢能力。
- **法遵與法規遵循** → 強調制度建置成果、與主管機關互動經驗、調查案件的處理過程。
- **公部門／公益律師** → 強調出庭量、在資源有限下的判斷力、對公共使命的投入。
- **法律科技／法律工程師** → 強調把執業專業轉譯為產品／流程決策的能力，以及採用率等具體成果。

同時包含：
- **代表案件／交易展示建議**：建議求職者在面試中展示哪一件案件或交易（在保密規範允許範圍內），以及展示的側重點。
- **防線陷阱問答**：針對 JD 潛在的痛點或求職者履歷上的弱點（例如「為什麼離開事務所」、「為什麼還沒升合夥人」、「你的計費工時／案件量紀錄如何」、「為什麼想從企業法務回事務所／從事務所轉企業法務」），設計高情商的擬答。

## 維度 G — 職缺真實性評估 (Posting Legitimacy)

深入分析職缺的刊登狀態與外圍訊號，判斷它是否為真正在招募的活躍職缺，幫助求職者避開只掛不招的「幽靈職缺」或純粹蒐集履歷的假管道。

**台灣市場特有訊號分析：**
1. **刊登時間與更新頻率**（透過 Playwright 網頁快照或 WebSearch 輔助）：
   - 104／1111 等平台上的「更新日期」「應徵人數」「急徵」標籤。
   - 職缺首次刊登日期與最近一次更新日期（掛超過 3 個月且頻繁更新的職缺要提高警覺）。
   - 同一家公司是否長期同時掛著數十個相似職缺（常見於人力仲介或儲備性掛單）。
2. **職缺描述的具體與詳實程度**：
   - 工作內容是否具體（有沒有提到公司具體的產品線或業務細節）。
   - 應徵條件是否寫實（例如同時要求「3 年內執業經驗」與「10 年以上訴訟經驗」這種時間軸矛盾的條件，或律師職缺卻完全未提及執業領域）。
   - 薪資區間的張力（例如「35,000 – 120,000」這種跨度過大的區間，通常代表實際給薪會偏低，或職缺只是虛掛）。
3. **外圍招募訊號**（透過 2–3 次 WebSearch 查詢）：
   - 查詢 `"{公司名稱}" 裁員 2026` 或 `"{公司名稱}" 勞資爭議`。
   - **查詢該公司是否列在勞動部「違反勞動法令事業單位查詢系統」的裁罰名單上**（這是台灣市場最直接、最公開的雇主風險訊號）。
   - 查詢該公司近期的募資狀態、財報或經營危機報導（上市櫃公司可查公開資訊觀測站）。
   - 若近期發生大規模裁員，評估該職缺所屬部門是否受到波及。
4. **歷史重複度偵測**（透過 `scan-history.tsv`）：
   - 檢查該公司是否在過去 90 天內重複刊登相同職能但不同連結的職缺。
5. **法律職缺特有訊號**：
   - **獵頭刊登的「機密事務所」「知名外商法務」等匿名徵才**：不代表一定是假職缺，但若沒有具名雇主、沒有明確的執業領域或年資要求，且描述空泛，應評為「需留意」；反之，若獵頭主動聯繫並能說明具體職缺內容，是正面訊號。
   - **同一職缺經 3 家以上獵頭重複刊登**：代表事務所或企業正在多管道尋才，職缺通常是真的，但流程可能較混亂——且務必在候選人投遞前，比對 `scan-history.tsv` 與 tracker 的 `via=` 欄位，避免管道衝突（見 `_shared.md` 的獵頭代理權規則）。
   - **收費「媒合」「代辦」服務**：正規的法律獵頭一律向雇主收費（成功媒合費約為第一年薪資的一定比例），從不向求職者收費。任何要求候選人支付媒合費、註冊費或「行銷費」的管道，一律標記為「疑似虛假」。
   - **以「法務」「法務專員」名義徵才，實際內容為行政助理或書記工作**：職稱與工作內容明顯不對等時，於報告中提醒求職者，避免用律師／法務職缺的框架準備面試。

### 輸出評級：

- **高信心 (High Confidence)** — 多個訊號互相印證，職缺確實處於急需且活躍的招募狀態。
- **審慎推進 (Proceed with Caution)** — 存在部分混合訊號（例如公司剛裁員，但該產品線是新設立的成長重點），建議投遞前先透過人脈確認。
- **疑似虛假／已過期 (Suspicious)** — 存在大量幽靈職缺指標，建議不要貿然花大量時間客製履歷。

## 評估後處理流程 (Post-evaluation)

**在產生 Block A–G 的評估結果之後，必須無條件執行以下兩個步驟：**

### 1. 儲存報告 markdown 檔案

將完整的評估內容儲存到本機路徑 `reports/{###}-{company-slug}-{YYYY-MM-DD}.md`。

- `{###}` = 依序遞增的 3 位數字（如 001, 002）
- `{company-slug}` = 公司英文名或拼音縮寫，全小寫，空格用連字號 `-` 取代
- `{YYYY-MM-DD}` = 評估當天的日期

**報告檔案格式模板：**

```markdown
# 評估報告: {公司名稱} — {職缺名稱}

**Score:** {X/5}
```
