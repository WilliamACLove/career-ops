# 模式: job — 完整的 A-G 维度评估

当候选人输入职位描述（JD文本或URL链接）时，**始终**输出以下七个维度的深度评估结果（A-F 评估 + G 真实性）：

## 步骤 0 — 岗位画像识别
将该职位划分为 6 种画像之一（参见 `_shared.md`）。如果是混合型，标明最接近的 2 种。这决定了：
- 在维度 B 中优先匹配哪些量化佐证（Proof points）。
- 在维度 E 中如何改写简历的专业总结。
- 在维度 F 中优先准备哪些 STAR 故事。

---

## 步骤 0.5 — 法律行业强制门槛（Legal Hard Gates，通过/不通过，绝不能被平均分掩盖）

在开始打分前，先对照候选人 `config/profile.yml` 中的 `legal:` 字段块核查该岗位。这些是结构性筛查项，不是加权因子——门槛未通过必须**明确**体现在"红线警告"维度和最终建议中，简历匹配度再高也不能悄悄抵消一个未通过的门槛。

1. **法律职业资格与执业证匹配** — 核对岗位所需资质与候选人的法考通过情况、执业证状态（对应 `legal.bar_admissions`）。适用从严到宽松的梯度：
   - **律所：从严。** 通常要求已取得执业证，或已通过法考并完成/即将完成一年实习期；若执业证注册地需要变更（"转所"），提前说明这通常是行政流程而非资格壁垒，但仍可能影响入职时间。
   - **公司法务/合规：宽松。** 多数法务、合规岗位不强制要求执业证；通过法考、具备法律职业资格通常是加分项，而非门槛，作为提示说明即可，不作为拦截条件。
   - **政府/公职律师、法律科技：最宽松。** 通常只需具备法律职业资格或相关法律背景，资质差异只是备注，不是拦截。
2. **执业年限/资历带宽匹配**（对应 `legal.class_year`）— 若律所招聘信息注明具体执业年限区间（如"3-5 年执业经验"、"20XX 届"），比对候选人的执业年限。明显不在区间内（尤其显著低于下限）视为近乎自动淘汰：建议候选人谨慎投递，并说明执业年限的重新认定（±1 年）通常只在 offer 阶段小幅协商，帮助有限。
3. **专利代理师资格**（对应 `legal.patent_bar`）— 专利代理业务需要专利代理师资格考试通过并完成执业备案。若 JD 要求专利代理资质而候选人不具备，视为硬性门槛。（商标、著作权及一般知识产权诉讼通常不需要此资格。）
4. **利益冲突风险**（高级顾问/合伙人层级）— 任何高级 offer 都以通过客户利益冲突审查为前提；一个客户冲突可能导致候选人资格被直接否决。仅在报告中提示风险，不纳入打分。

在维度 B 顶部以简短的通过/不通过表格呈现门槛核查结果。未通过的门槛无论其余匹配度多高，都必须压低最终建议。

## 维度 A — 岗位概览 (Role Summary)
输出包含以下信息的表格：
- 检测到的角色画像 (Archetype detected)
- 执业领域 (Domain - 非诉/交易、诉讼、公司法务、合规、政府、法律科技等)
- 岗位职能 (Function - 谈判起草/出庭代理/管理/合规建设/赋能等)
- 资深程度 (Seniority - 律所对应执业年限/届别，公司法务对应职级)
- 工作模式 (Remote - 全远程/混合/现场)
- 团队规模 (Team size - 若JD中提及)
- 一句话总结 (TL;DR)

## 维度 B — 简历匹配分析 (Match with CV)
读取 `cv.md`。创建一个对照表格，将 JD 中的各项硬性/软性要求一一映射到简历中的具体行号和量化表述上。

**针对不同岗位画像的分析侧重点：**
- **律所律师 — 非诉/交易方向** → 侧重与执业年限相匹配的交易履历：主办交易的类型与规模、尽职调查主导、合同起草与谈判、专项工作组的管理经验。
- **律所律师 — 诉讼与争议解决** → 侧重出庭/开庭经验：主导或参与的仲裁案件数量、代理词/上诉状等法律文书撰写能力、举证质证与庭审应变能力。
- **公司法务 — 产品/商务/数据合规** → 侧重合同处理量（销售合同/采购合同/数据合作协议等）、跨部门业务沟通、监管覆盖广度、向非法律背景同事解释法律风险的能力。
- **合规与监管** → 侧重具体监管领域（反洗钱/AML、反商业贿赂、数据合规、行业牌照等）、与监管机构的对接经验、调查处理经验、合规体系建设与推行。
- **政府/公职律师** → 侧重办案量、出庭/出席听证经验、公益或公共服务背景（法律援助、相关实习经历等）。
- **法律科技 / 法律工程师** → 侧重扎实的执业背景加上真实的产品/AI 技能：搭建过的法律工作流、自动化文书模板、法律科技相关的个人项目。

**能力差距 (Gaps) 与弥补策略：**
针对识别出的每一项能力差距，提供以下应对方案：
1. 这是一项硬性门槛（Blocker）还是加分项（Nice-to-have）？
2. 候选人是否有其他相近或可迁移的经验来作等价替换？
3. 是否可以通过一个快速的项目作品或文章来填补此空白？
4. 具体的弥补行动指南（如在自荐信中如何避重就轻、准备怎样的话术）。

## 维度 C — 级别判断与求职策略 (Level and Strategy)
1. **JD 所对应的实际职级** vs **候选人针对该画像的自然职级**——律所岗位以执业年限/届别比对为准（从严，见步骤 0.5 强制门槛）；公司法务岗位以职级阶梯为准（法律顾问 → 高级法律顾问 → 法务副总监/法务总监 → 首席法务官/GC），**职级本身就是薪酬谈判的关键杠杆**。
2. **“包装资深度（实事求是）”计划**：提供针对该画像的特定自荐话术，突出体现资深度的具体交易/案件成果，并说明如何将律所培训背景、政府/检察机关经历或监管机构对接经验转化为竞争优势。
3. **“如果对方给的级别偏低”预案**：律所岗位——执业年限的重新认定通常只在 offer 阶段有 ±1 年的协商空间（有时降一年也可能换来更快的合伙人晋升通道）；公司法务岗位——先争取职级/title（如高级法律顾问 vs. 法律顾问、法务副总监 vs. 高级法律顾问），再谈薪资数字，因为奖金比例和期权额度通常与职级挂钩。

## 维度 D — 薪酬竞争力与市场需求 (Comp and Demand)
使用 WebSearch 工具，按雇主类型使用对应的薪酬参考渠道：
- **律所（非诉/诉讼）：** 律所官网公开的校招/社招信息、涉外与精品所方向的猎头及国际猎头公司在华法律条线反馈的市场行情；红圈所/精品所之间没有公开统一的薪级表，薪酬弹性较大，数字仅供粗略参考。
- **公司法务/合规：** 智联招聘、猎聘、BOSS直聘等平台的薪酬数据，以及猎头对特定公司/职位的市场反馈。
- **政府/公职律师：** 参照当地公务员薪级及职务对应的工资标准（具体数额因地区、单位性质差异较大，不做具体数字假设）。
- **法律科技：** 参考同等规模科技公司的薪酬体系，并结合公司融资阶段判断弹性空间。
- 该公司在行业内的薪酬声誉（如五险一金是否足额缴纳、年终奖兑现率、竞业限制补偿是否合规等）。
- 该职位的市场需求趋势（是急招岗位还是常态化挂靠储备）。

在解释薪资数字前，必须先判断公司类型。公开薪资区间不能直接等同于合同固定 base 或稳定到手。

**公司类型分类（必填）：**

将招聘主体归入最接近的一类，并给出置信度。法律行业雇主类型优先套用：

| 公司类型 | 典型薪资可信度 | 识别信号 |
|---|---|---|
| 红圈所 / 顶级涉外精品所 | 高 — 相对规范 | 知名综合大所或涉外精品所，起薪及涨薪梯度可比对历年校招/社招信息，奖金随个人创收/评级浮动，通常无公开统一薪级表 |
| 中型/区域律所、一般精品所 | 中 | 薪酬缺乏统一标准，"薪资面议"常见，提成/分成比例因所而异 |
| 公司法务 — 大型企业/上市公司 | 中到高 | 职级体系较清晰（法律顾问 → 首席法务官阶梯），base + 奖金 + 期权结构，猎聘/BarkerGilmore 式行业调研数据是区间参考而非精确值 |
| 公司法务 — 创业公司/成长期企业 | 中到低 | 期权占比高，title 存在通胀空间，职级和奖金目标可协商 |
| 法律外包 / 驻场审核（合同审核、尽调支持等） | 低 | 常以"法务专员/法律顾问"名义招聘，按小时或按项目计费，用工关系可能是外包或劳务派遣 |
| 猎头代理岗位（律所或公司法务） | 低到中 | 第三方猎头发布，薪资区间可能反映委托方预算而非最终 offer |
| 政府/司法机关/公职律师 | 高 | 薪级/职务对应工资标准相对公开，但市场竞争力通常低于律所/头部企业 |
| 法律援助/公益组织 | 中到高 | 薪级公开，通常明显低于律所起薪，需结合候选人的公益动机评估 |
| 法律科技 | 中 | 参考同等规模科技公司薪酬体系，股权/期权占比可能较高 |

若雇主不属于上述法律类别（例如一家非法律行业公司首次招聘法务），回退到通用公司类型分类：

| 公司类型 | 典型薪资可信度 | 识别信号 |
|---|---|---|
| 大厂 / 成熟科技公司 | 高到中 | 上市公司、职级体系清晰、工程团队规模大、招聘流程规范 |
| 成长期创业公司 / 已融资创业公司 | 中 | 有融资或收入增长，薪资可能混合 base、期权、奖金 |
| 早期初创企业 / 未盈利创业公司 | 中到低 | 团队小、岗位边界模糊、期权承诺多、薪资 band 不清晰 |
| 传统企业 / 大型集团 | 中 | HR 流程正式，固定薪资较稳定，但奖金可能浮动 |
| 外包 / 咨询 / 乙方服务商 | 中到低 | 项目制、客户派驻、billability 压力、项目奖金不稳定 |
| 本地中小企业 / 服务业公司 | 低 | 小公司、HR 不规范、常见“综合薪资”写法 |
| 销售 / 提成驱动型公司 | 低，除非 base 写清楚 | OTE、上不封顶、底薪加提成、业绩 KPI |
| 猎头 / 第三方招聘岗位 | 低到中 | 第三方发布，薪资可能是客户预算而非最终 offer |
| 政府 / 高校 / 非营利组织 | 中到高 | 薪级或等级公开，但市场竞争力可能偏低 |
| 开源社区 / 教育社区 | 中到低 | 社区型组织、协会/基金会/学校/合作方承接、实际用工主体不清 |

如果品牌方和实际招聘/签约主体不同，优先按**实际合同主体 / 用工主体**分类，再说明品牌关系。公司类型不确定时，标记为 `Unknown`，薪资可信度默认使用保守的正式等级：`低`。

**薪资可信度（必填）：**

先检查 JD 本身是否存在薪资 / 补偿信息。若 JD 没有任何公开薪资数字，也没有“综合薪资”“底薪+提成”“含绩效”“含全勤”“最高可达”等模糊补偿表述，本节在需求趋势后只输出两行：

- **公司类型：** {类别或 `Unknown`} — {置信度 + 一个证据短语}
- **薪资可信度：** {等级} — JD 未提供薪资 / 补偿信息；跳过薪资组成拆分、详细市场数据表和 HR 核验问题

当 JD 明确写出薪资数字，或仅出现“综合薪资”“底薪+提成”“含绩效”“含全勤”“最高可达”“上不封顶”等模糊补偿表述时，进入完整薪资可信度路径，并拆分以下五项：

- **公开薪资区间：** JD 原文写出的薪资，必须逐字保留。
- **可能的合同固定 base：** 对劳动合同中固定薪资的保守估计。
- **浮动 / 条件性现金组成：** 绩效、全勤、提成、补贴、加班费、年终奖、项目奖金等现金项。
- **预计稳定现金收入：** 大概率稳定发放的现金部分。除非本地数据足够，否则默认按税前口径说明；不要把福利算入稳定现金。
- **非现金福利：** 期权、五险一金、餐补、交通、培训预算、设备等不等同于固定现金的福利。

可信度分级：

| 等级 | 含义 |
|---|---|
| 高 | 明确写为固定 base，或有公开薪级/多方一致数据支撑 |
| 中 | 区间大体可信，但薪资组成未完全拆开 |
| 低 | 公开数字很可能包含绩效、全勤、提成、补贴或“最高可达”部分 |
| Unknown | 没有可用薪资数据 |

遇到以下表达，除非固定 base 单独写清楚，否则默认按低可信处理：“综合薪资”“最高可达”“上不封顶”“底薪+提成”“包含补贴”“含绩效”“含全勤”“KPI 奖金”“13薪已包含”或跨度异常大的薪资区间。

当 JD 明确写出薪资数字，或出现模糊补偿表述时，必须给出 3-6 个 HR 核验问题，例如：

- 劳动合同上写明的固定 base 是多少？
- 公开薪资是否包含绩效、全勤、提成、补贴、加班费或年终奖？
- 试用期薪资是否打折？五险一金是否足额缴纳？
- 哪些组成是每月固定发放，哪些取决于考勤、KPI 或公司利润？
- 如果包含期权或奖金，归属周期、历史兑现率和实际预期价值是多少？

当 JD 明确写出薪资数字，或出现模糊补偿表述时，以表格形式展示查询数据并标明信息源。如果除了 JD 原文外没有查到可靠数据，如实说明，切勿捏造。
除非来源明确支持，否则不要把招聘广告薪资当作真实到手。

## 维度 F — 面试备考计划 (Interview Plan)
根据 JD 的具体要求，从候选人的工作经验中筛选并重新包装 6-10 个 STAR+R 故事（STAR + **Reflection/反思**）：

| # | 对应 JD 需求 | 故事名称 | 情境 (S) | 任务 (T) | 行动 (A) | 结果 (R) | 反思与总结 (Reflection) |
|---|---|---|---|---|---|---|---|

在**反思**列中，务必提炼出学到的核心教训或如果重新来过会如何改进。这对于体现资深度至关重要——初级候选人只描述过程，资深候选人能提炼方法论。

**故事库同步：** 如果存在 `interview-prep/story-bank.md`，检查这些故事是否已在故事库中。如果不存在，将其追加进去，以便随着评估逐渐建立一个可随时调用的“黄金面试故事库”。

**根据画像进行故事包装：**
- **律所律师 — 非诉/交易方向** → 强调交易执行、起草文件的主导权、专项工作组的管理经验。
- **律所律师 — 诉讼与争议解决** → 强调案件策略、胜诉的动议/申请、出庭或仲裁经验、高压下的文书撰写能力。
- **公司法务 — 产品/商务/数据合规** → 强调业务赋能（"安全地促成业务"）、合同处理量、跨部门沟通协调。
- **合规与监管** → 强调合规体系建设、与监管机构的沟通、调查处理经验。
- **政府/公职律师** → 强调办案量、在资源有限条件下的判断力、公共服务使命感。
- **法律科技 / 法律工程师** → 强调把执业经验转化为产品/工作流决策的能力，以及采用率等指标。

同时包含：
- **核心代表性案件/交易推荐**：推荐候选人在面试中重点讲述哪一个交易或案件，以及讲述的侧重点——务必提醒候选人只讨论已公开披露（交易已公告/案件已立案审理）的信息，或采用去标识化的一般性描述（如"某世界 500 强制造业客户"），不违反保密义务。
- **防线陷阱问答**：针对 JD 潜在的痛点或候选人简历中的弱点设计高情商拟答，例如"为什么想从现在的律所/公司离职"、"为什么还没有晋升合伙人"、"如何看待计效工时/billable hours 考核"、"为什么从律所转法务"或"为什么想从法务回律所"。

## 维度 G — 职位真实性评估 (Posting Legitimacy)
深入分析职位的发布状态与外围信号，判断其是否为活跃招聘职位，帮助求职者避开只挂不招的“幽灵职位”或收集简历的虚假通道。

**中国大陆市场特有信号分析：**
1. **发布时间与更新频率** (通过 Playwright 网页快照或 WebSearch 辅助)：
   - BOSS直聘等平台的“活跃/今日活跃/刚刚在线”状态。
   - 职位首次发布日期及最近一次刷新日期（挂靠超过3个月且频繁刷新的岗位需警惕）。
2. **职位描述的具体与详实度**：
   - 岗位职责是否具体（是否提到了公司具体的业务线或产品细节）。
   - 任职资格是否写实（如“精通 langchain”与“10年以上大模型经验”这种不切实际要求的矛盾点）。
   - 薪资范围的张力（如“15k - 45k”这种跨度过大的薪酬区间，通常预示着实际给薪会偏低，或者岗位只是虚挂）。
3. **外围招聘信号** (通过 2-3 个 WebSearch 查询)：
   - 查询 `"{公司名称}" 裁员 2026` 或 `"{公司名称}" 劳动纠纷`。
   - 查询该公司的近期融资状态或经营危机报道。
   - 若近期发生大规模裁员，评估该岗位所属部门是否受到波及。
4. **历史重合度检测** (通过 `scan-history.tsv`)：
   - 检查该公司是否在过去 90 天内重复挂牌相同职能但不同链接的岗位。
5. **法律行业特有信号**：
   - **猎头"匿名大所"广告**：部分猎头会以"某红圈所"/"某涉外精品所"等匿名方式发布岗位广告钓取简历，背后未必有真实、明确的委托职位。若广告始终不透露具体所名、无明确执业年限要求、描述泛泛，作为"谨慎"信号看待；反之，猎头能明确说出委托方所名及具体职级需求，是积极信号。
   - **文件审核/驻场审核外包岗**：以"律师"或"法律顾问"名义招聘的合同审核、尽调支持、驻场审核类岗位，多为按小时或按项目计费的外包/劳务派遣性质工作，并非传统意义上的律所执业岗位，需向候选人说明区别，避免其误当作正式 lateral 机会投递。
   - **同一岗位被多家猎头同时代理**：说明该律所在公开市场"广撒网"寻猎，岗位本身通常是真实的，但流程可能比较混乱；由于猎头推荐权通常归属首个提交简历的猎头（保护期以双方协议为准），候选人务必在投递前核查 `data/scan-history.tsv` 及 tracker 中该公司对应行的 `via=` 字段，避免"简历撞车"。
   - **收费"内推"/"包过"服务**：正规猎头的报酬始终由用人单位（律所/企业）支付，从不向候选人收费。任何要求候选人支付内推费、注册费或"保过"费用的招聘信息或私信，应视为诈骗信号，标记为"疑似虚假"。

### 输出评级：
- **高置信度 (High Confidence)** -- 多个信号印证岗位确实处于紧缺且活跃的招聘状态。
- **谨慎推进 (Proceed with Caution)** -- 存在部分混合信号（如公司刚裁员但该业务线为新设立的增长点），建议投递前通过人脉确认。
- **疑似虚假/已过期 (Suspicious)** -- 存在大量幽灵岗位指标，建议不要盲目花费大量时间定制简历。

### 1. 保存报告 markdown 文件
